# zetaalpha.rag-agents

**This package has been renamed to [`zetaalpha.agents`](https://pypi.org/project/zetaalpha.agents/).**

Installing `zetaalpha.rag-agents` will automatically install `zetaalpha.agents`.
For new projects, use:

```bash
pip install zetaalpha.agents
```

All extras are forwarded: `pip install zetaalpha.rag-agents[cli]` installs `zetaalpha.agents[cli]`, etc.
